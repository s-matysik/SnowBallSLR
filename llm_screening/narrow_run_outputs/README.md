# Narrow run — PRISMA outputs

The run that terminated on a saturation rule rather than a budget. Generated by
`snowballslr report` from `run_narrow/`, which is not tracked (116 MB of cached API
responses and per-iteration state).

- `prisma.json`, `prisma.svg` — PRISMA 2020 flow counts and diagram
- `included.csv` — the 585 included studies with keys, titles and years
- `report.md` — the run's own methods-section text, including the stop rationale
- `run.json` — the run manifest: config snapshot and artefact hashes, which
  `snowballslr verify ./run_narrow` recomputes (14 artefacts, 1,064 cache entries, no mismatch)

Stopped by: **exhaustion** after 10 iterations, 10,878 records screened, 591 included,
using 54% of the 20,000-record budget it was allowed. The per-iteration trajectory and
the estimated-population trail are in `../../cases/narrow_run.json`; reproduction code is
`../../cases/narrow_driver.py` with seeds in `../../cases/narrow_seeds.json`.
